## 🌟 မိတ်ဆက် (Introduction)
ဤ Repository သည် ဂျပန်အစိုးရ (MEXT) သုတေသနပညာသင်ဆု (Research Students Program) ကို လျှောက်ထားလိုသည့် မျိုးဆက်သစ် မြန်မာကျောင်းသား/သူများအတွက် ရည်ရွယ်၍ ဖန်တီးထားသော အဆင့်မြင့် လမ်းညွှန်စာတမ်းစုရပ် ဖြစ်ပါသည်။[cite: 1] 

ပညာသင်ဆု လျှောက်လွှာတင်သွင်းသည်မှစ၍ နောက်ဆုံးအဆင့် ဂျပန်သံရုံး လူတွေ့အင်တာဗျူးကြီး အောင်မြင်သည်အထိ အဆင့်တစ်ခုချင်းစီအတွက် ကိုယ်တွေ့အတွေ့အကြုံများနှင့် တရားဝင် စည်းမျဉ်းများအပေါ် အခြေခံထားသော ဗျူဟာများကို စနစ်တကျ ပြုစုမျှဝေပေးထားပါသည်။[cite: 1]

## 📚 လမ်းညွှန်စာတမ်းများ (The 7 Golden Guidelines)
Repository အတွင်းတွင် အောက်ပါ မူရင်း Markdown (`.md`) ဖိုင် (၇) စောင်အား အလွယ်တကူ လေ့လာနိုင်ရန် ခွဲခြားပေးထားပါသည်-

1. **`mext-2027-complete-roadmap-v2.md`** 
   - **Master Roadmap:** Step 0 မှ Step 5 အထိ အဆင့်ဆင့် ကျော်ဖြတ်ရမည့် အဓိက လမ်းပြမြေပုံ အပြည့်အစုံ။[cite: 1]
2. **`mext-step0-proposal-guideline.md`** 
   - **Step 0 Guideline:** A+ Grade Research Proposal တည်ဆောက်နည်း၊ HRI သုတေသန သီအိုရီ ကိုးကားပုံနှင့် နှစ်နိုင်ငံအကျိုးပြုမှု (Bilateral Impact) ရေးသားနည်းများ။[cite: 2]
3. **`mext-step1-application-guideline.md`** 
   - **Step 1 Guideline:** MAJA သို့ Hard Copy ပေးပို့နည်း၊ သံရုံး Digital Submission (10MB Limit) နှင့် Document Numbering Rule ① မှ ⑪ အကြောင်း။[cite: 3]
4. **`mext-step2-maja-written-guideline.md`** 
   - **Step 2 Guideline:** MAJA အင်္ဂလိပ်စာ/ဂျပန်စာ ရေးဖြေစာမေးပွဲ ဗျူဟာ၊ Online Device (၂) ခု ကင်မရာချိန်ညှိမှုနှင့် "စာရွက်အလွတ် လုံးဝမချန်ရ" ရွှေစည်းကမ်း။[cite: 4]
5. **`mext-step3-maja-interview-guideline.md`** 
   - **Step 3 Guideline:** MAJA ပဏာမ အင်တာဗျူး မေးခွန်း (၅) ခု၊ နည်းပညာပိုင်းဆိုင်ရာ ထိုးနှက်ချက်ကို ဖြေရှင်းမည့် **"Ma Phoo Defense (Humility Pivot)"** ဗျူဟာ။[cite: 5]
6. **`mext-step4-embassy-written-guideline.md`** 
   - **Step 4 Guideline:** ရန်ကုန် MAJA Center တွင် လူကိုယ်တိုင် ဖြေဆိုရသော သံရုံးရေးဖြေ စာမေးပွဲ စည်းကမ်းများနှင့် Advanced Spelling/Grammar လေ့ကျင့်ရေး။[cite: 6]
7. **`mext-step5-embassy-interview-guideline.md`** 
   - **Step 5 Guideline:** သံရုံး နောက်ဆုံးအဆင့် အင်တာဗျူး Vibe Check၊ **"Wizard-of-Oz vs Autonomous"** ခြေပနည်းနှင့် အောင်မြင်ပြီးနောက် LOA တောင်းခံခြင်း လမ်းညွှန်။[cite: 7]
